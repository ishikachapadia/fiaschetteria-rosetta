# Fiaschetteria Rosetta — Website

Marketing website for **Fiaschetteria Rosetta**, an authentic Italian eatery & market
in Brooklin (Whitby), Ontario — designed and built by
[Ishika Chapadia](https://github.com/ishikachapadia).

**Live site:** https://fiaschetteriarosetta.com

## About the project

Single-page static site with separate menu image spreads, a photo gallery with
lightbox, private events and market (Mercatino) sections, a wine club section,
and intro/wine-club videos.

## Tech

- Semantic HTML5
- CSS3 (custom properties, responsive layout)
- Vanilla JavaScript + Lightbox (jQuery plugin)
- Google Fonts (Tenor Sans, Alegreya Sans), Font Awesome

## Structure

- `index.html` — the full page
- `css/` — main styles, reset, lightbox styles
- `js/` — site script + vendor lightbox
- `assets/` — images, videos, favicons
